Build a single-page web application called "Tilawet Analizör" for ilimsaray.com. This is a real-time AI-powered Quran recitation (tilawet) analysis tool. No login or registration required — users can use it immediately.

---

TECH STACK:
- Frontend: HTML, CSS (vanilla or Tailwind), vanilla JavaScript
- Backend: Node.js + Express (or a single serverless function)
- AI: OpenAI API (Whisper for transcription + GPT-4o for analysis)
- Audio: MediaRecorder API (in-browser recording)
- No database needed — stateless, per-session usage

---

OPENAI INTEGRATION:
- Use the user-provided OpenAI API key (input field on the page, stored only in sessionStorage — never sent to a server except for the API call itself)
- Use Whisper (whisper-1) to transcribe the recorded Arabic audio
- Use GPT-4o to analyze the recitation based on scoring criteria
- Pass the transcribed Arabic text and audio context to GPT-4o for evaluation

---

SCORING SYSTEM (100 points total):
GPT-4o must evaluate the recitation on exactly these 5 criteria:

1. Taban puan (Base score) — 50 points
   Measures: general correctness of the recitation, completeness, no major errors

2. Tecvid ve mahreç (Tajweed & articulation) — 15 points
   Measures: proper tajweed rules application, correct makhraj (articulation points of letters)

3. Yüzünden doğru okuma (Reading from text accurately) — 15 points
   Measures: accuracy of reading the words correctly as they appear in the Quran

4. Makam (Melodic tone/maqam) — 15 points
   Measures: proper use of traditional Quranic melodic modes (maqamat)

5. Ses (Voice quality) — 5 points
   Measures: clarity, projection, and quality of voice

The GPT-4o system prompt should instruct it to respond ONLY in JSON format:
{
  "scores": {
    "taban_puan": <0-50>,
    "tecvid_ve_mahrec": <0-15>,
    "yuzunden_dogru_okuma": <0-15>,
    "makam": <0-15>,
    "ses": <0-5>
  },
  "total": <0-100>,
  "feedback": {
    "taban_puan": "",
    "tecvid_ve_mahrec": "",
    "yuzunden_dogru_okuma": "",
    "makam": "",
    "ses": ""
  },
  "genel_yorum": "",
  "transcribed_text": ""
}
